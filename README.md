# The Kate Treasury

A responsive static showcase for fine jewellery and antiques.

## Open locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
Upload the entire folder to Netlify, Cloudflare Pages, GitHub Pages, or your web host.

## Before launch
1. Replace `https://thekatetreasury.com` in every HTML page, `robots.txt`, and `sitemap.xml` if your final domain differs.
2. Replace the demonstration email address.
3. Connect the enquiry form to Netlify Forms, Formspree, or a backend.
4. Replace illustrative catalogue entries with verified inventory, prices, measurements, condition reports and provenance.
5. Replace SVG editorial illustrations with your own licensed photographs and accurate alt text.
6. Add real social profiles to the Organization JSON-LD when available.
7. Submit `sitemap.xml` in Google Search Console after the domain is live.

## Folder structure
- `index.html` – homepage
- `404.html` – custom error page
- `pages/` – jewellery, antiques, about, journal and contact
- `assets/css/` – styles
- `assets/js/` – catalogue data and interactions
- `assets/images/brand/` – logo and favicon
- `assets/images/products/` – original SVG catalogue artwork
- `robots.txt`, `sitemap.xml`, `site.webmanifest` – discovery and app metadata
